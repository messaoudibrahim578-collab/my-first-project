# 🎓 أكاديمية عائشة (Aisha Academy)

مرحباً بكم في **أكاديمية عائشة**، منصة تعليمية شخصية وتفاعلية تعتمد على تقنيات الذكاء الاصطناعي (مثل NotebookLM) لدعم مسار التعليم في المرحلة الثانوية.

## 🎯 الهدف من المشروع
يهدف هذا المشروع إلى تبسيط المناهج الدراسية، وتوليد ملخصات دقيقة، وإنشاء بيئة تفاعلية لمواد التخصص العلمي.

## 📚 المواد الأساسية
* 📐 **الرياضيات:** التركيز على البراهين، الهندسة، والدوال.
* ⚛️ **الفيزياء:** ميكانيكا الأشعة، القوانين الفيزيائية، والتطبيقات.
* 🧬 **العلوم الطبيعية:** تبسيط المفاهيم العلمية المعقدة.

## 📂 هيكلة المشروع
* `Lessons/`: يحتوي على ملخصات الدروس المستخرجة والمنسقة.
* `Prompts/`: يضم الأوامر الهندسية الدقيقة الموجهة للذكاء الاصطناعي.
* `Web-App/`: ملفات واجهة المستخدم (HTML/CSS/JS) لتقديم المحتوى بشكل تفاعلي.
